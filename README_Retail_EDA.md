# Retail Data Analysis Using Python

## Project Overview
This project demonstrates data cleaning, exploratory data analysis (EDA), visualization, correlation analysis, and basic hypothesis testing using Python.

## Objectives
- Inspect and understand retail order data.
- Clean missing, duplicate, inconsistent, and invalid values.
- Calculate descriptive statistics.
- Visualize numeric distributions using histograms and box plots.
- Explore relationships using correlation analysis.
- Test three business-related hypotheses.
- Summarize findings and limitations.

## Tools and Libraries
- Python
- Jupyter Notebook / Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Repository Files
- `Retail_EDA_Statistical_Insights.ipynb` – EDA notebook with code, charts, and commentary.
- `Retail_Data_Cleaning_Preprocessing.ipynb` – data-cleaning notebook, if included.
- `retail-orders-raw.csv` – original dataset.
- `retail-data-dictionary.csv` – description of dataset columns.
- `clean_dataset.csv` – cleaned dataset.
- `requirements.txt` – Python library requirements.

## How to Run
1. Download or clone this repository.
2. Open the EDA notebook in Jupyter Notebook or Google Colab.
3. Upload `clean_dataset.csv` when the notebook requests it, or update the file path.
4. Run the notebook cells from top to bottom.

## Important Dataset Limitation
The practice source dataset contains 12 raw records and the cleaned dataset contains 6 records. Therefore, the statistical tests and patterns are illustrative only and should not be treated as reliable general business conclusions. A larger dataset is required for robust inference.

The source data does not contain product cost, so actual profit margin cannot be calculated from the available columns.
